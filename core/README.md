# core

Django project package: settings, URL config, and WSGI/ASGI entry points.

## Files

| File | Description |
|------|-------------|
| `asgi.py` | ASGI application entry for async servers |
| `settings.py` | Django settings (DEBUG, INSTALLED_APPS, DATABASES, etc.) |
| `urls.py` | Root URL configuration (admin, future app routes) |
| `wsgi.py` | WSGI application entry for production servers |
