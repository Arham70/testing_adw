# Django CRUD App with Auth

Django application with full CRUD, models, and authentication (Linear project: Django CRUD App with Auth).

## Quick start

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

- Admin: http://127.0.0.1:8000/admin/
